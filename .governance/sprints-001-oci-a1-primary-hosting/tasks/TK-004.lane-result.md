## Known residual risks

- The remote branches were not executed against oci-a1 (remote changes are out of scope). First real run will be the first live exercise of `tailscale funnel status` output wording; if that command errors instead of printing `No serve config`, the preflight aborts loudly rather than continuing — safe but may need a follow-up wording tweak.
- The release-keys import fetches all 29 fingerprints from `keys.list` (active + retired) — 29 small HTTPS requests per Node install; acceptable for a one-time bootstrap, and it avoids guessing which key signed the v22.23.4 release.
- `tar -xJf` relies on `xz-utils`, present by default on Ubuntu 24.04 but not explicitly preflighted; a missing binary fails the extract step with a clear error.
- `sqlite3` install assumes apt indexes are usable; no `apt-get update` is run (not requested), so a stale/empty index would surface as an install failure.
